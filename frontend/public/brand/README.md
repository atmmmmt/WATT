# مكان ملفات هوية VAYRO

## اللوغو
ضع الملفات هنا (نفس الأسماء بالضبط):

  vayro-logo.svg          الشعار الأفقي الأساسي (يُستخدم تلقائياً في لوحة التحكم)
  vayro-logo-white.svg    نسخة بيضاء للخلفيات الداكنة
  vayro-mark.svg          الرمز فقط (حرف V مع النقطة)

إذا لم توجد هذه الملفات، يرسم التطبيق نسخة احتياطية من الشعار تلقائياً — لا شيء ينكسر.

## الشخصية (المسكوت)
ضعها في `public/mascot/` بخلفية شفافة (PNG أو WebP)، بارتفاع ~700px:

  idle.png        الوضع الافتراضي (أمام أو أمام مائل)   ← مطلوب
  wave.png        تحية (تظهر عند مرور المؤشر)
  working.png     يعمل على اللابتوب
  thumbs.png      ممتاز
  thinking.png    مفكر
  pointing.png    يشير

الأسماء ثابتة لأن المكوّن يستدعيها بها مباشرة.
